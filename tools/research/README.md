# Research data and tools

This folder contains the `afre.py` helper and recovered object, protocol, and symbol data for Assault Fire PH **v1.0.0.24**.

These files are version-specific research references. They are not a complete protocol specification and should not be treated as runtime configuration for another game build. Preserve the source/version context when adding findings, and distinguish verified observations from hypotheses.

See [Research Findings](../../docs/RESEARCH_FINDINGS.md), [Reverse-Engineering Tooling](../../docs/RE_TOOLING.md), and the [main README](../../README.md).
