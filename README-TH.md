# Assault Fire Server Emulator

**ภาษา:** [English](README.md) | [Tagalog](README-TL.md) | [Cebuano](README-CEB.md) | [简体中文](README-ZH-CN.md) | [ภาษาอื่น](README-LANGUAGES.md)

โครงการไม่เป็นทางการสำหรับเก็บรักษา **Assault Fire PH** และจำลองเซิร์ฟเวอร์ของเกม โครงการนี้และเซิร์ฟเวอร์ที่บุคคลอื่นเป็นผู้ดูแลไม่ได้เกี่ยวข้อง ได้รับการสนับสนุน หรือได้รับการรับรองจาก Tencent, Level Up! Games หรือเจ้าของสิทธิ์ดั้งเดิม เซิร์ฟเวอร์ชุมชนดำเนินงานอย่างเป็นอิสระ

> **รองรับและทดสอบเฉพาะ:** Assault Fire PH **v1.0.0.24** รีโพซิทอรีนี้ไม่มีไฟล์เกม คุณต้องมีไฟล์เกมของตนเอง

## วิธีเริ่มที่ง่ายที่สุด

1. วางโฟลเดอร์ `af-emulator` ทั้งหมดไว้ในโฟลเดอร์เกม Assault Fire PH
2. คลิกขวาที่ `START_ASSAULT_FIRE.ps1` แล้วเลือก **Run with PowerShell** อนุญาตสิทธิ์ Administrator หาก Windows ขอ
3. ตัวเปิดเกมจะตรวจสอบเวอร์ชันและการตั้งค่า เตรียมกุญแจภายในเครื่อง แล้วเริ่มเซิร์ฟเวอร์ ตัวช่วยเปิดเกม และไคลเอนต์
4. เข้าสู่ระบบในไคลเอนต์ เมื่อปุ่ม **START** ปรากฏ ให้คลิกเพื่อดำเนินการต่อ

ในขั้นตอนแบบคลิกครั้งเดียวตามปกติ คุณไม่ต้องเริ่มเซิร์ฟเวอร์หรือเครื่องมือแพตช์เอง สคริปต์จะไม่ดาวน์โหลดหรือแจกจ่ายไฟล์เกม แต่ใช้ไฟล์ในเครื่องของคุณเท่านั้น หากเวอร์ชันไม่ตรงกันหรือยืนยันลายเซ็นของ `TGame.exe` หรือ `TCLS.dll` ไม่ได้ ให้หยุดและอย่าบังคับใช้แพตช์ ก่อนเปิดเกม ตัวเปิดเกมจะติดตั้งแพตช์วันเวลาแบบถาวรที่ตรวจสอบแล้วลงใน `TGame.exe` หลังจากบันทึกไฟล์สำรองที่เหมือนกันทุกไบต์ชื่อ `TGame.exe.bak` หากไม่มีพื้นที่โค้ดที่ปลอดภัย จะเพิ่มส่วน PE ที่เรียกใช้ได้ขนาดเล็ก `.afdt` เฉพาะเมื่อมีช่องส่วนที่ว่างในส่วนหัว PE เท่านั้น มิฉะนั้นจะไม่แก้ไขไฟล์

## การตั้งค่าด้วยตนเองและสำหรับนักพัฒนา

ดูขั้นตอนและคำสั่งทั้งหมดใน[คู่มือภาษาอังกฤษฉบับเต็ม](README.md) ต้องใช้ Windows, Python 3.10 ขึ้นไป และไฟล์เกมเวอร์ชันที่รองรับซึ่งคุณมีอยู่แล้ว เมื่อตั้งค่าด้วยตนเอง ให้รอจน preflight แสดง `UNLOCKED` หากเปิดเกมเอง อย่าคลิก **START** จนกว่าตัวช่วยจะแสดง `TCLS ARMED` ตัวเลือก `--server-only` ใช้สำหรับโฮสต์เซิร์ฟเวอร์เท่านั้น และไม่ได้ปลดล็อกการเปิดเกมในเครื่อง

## สถานะและการขอความช่วยเหลือ

ฐานเสถียรสาธารณะปัจจุบันคือ **v143b** เส้นทาง VERSION, AUTH, DIR, ROLE และ ZONE การจัดการห้อง และการเล่น PvE ใช้งานได้ การสร้างชื่อเล่น/บัญชีครั้งแรกและฟีเจอร์สังคม/ความคืบหน้าบางส่วนยังอยู่ระหว่างพัฒนา การซิงก์ AP ครั้งแรกในไคลเอนต์ยังใช้วิธีแก้ไขเฉพาะเครื่องชั่วคราว

เมื่อขอความช่วยเหลือ ให้ส่งภาพหน้าจอข้อผิดพลาด ขั้นตอนที่ทำ คำสั่งที่ใช้จริง `server/af_server_live.log` และเวอร์ชันเกม **ห้ามส่ง** `PRIVATE.PEM` รหัสผ่าน ข้อมูลบัญชี โทเค็น หรือไฟล์เกมต้นฉบับ
